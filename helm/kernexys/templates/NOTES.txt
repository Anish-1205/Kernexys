Kernexys control plane installed into namespace {{ .Values.namespace.system }}
{{- if .Values.worker.enabled }} (workers in {{ .Values.namespace.workers }}){{- end }}.

Before workloads become ready, create the referenced Secrets (see docs/security.md):

  kubectl create secret generic {{ .Values.api.secrets.database.name }} \
    --from-literal={{ .Values.api.secrets.database.key }}='postgresql+asyncpg://user:pass@host:5432/db' \
    -n {{ .Values.namespace.system }}

  kubectl create secret generic {{ .Values.api.secrets.redis.name }} \
    --from-literal={{ .Values.api.secrets.redis.key }}='redis://:password@host:6379/0' \
    --from-literal=password='password' \
    -n {{ .Values.namespace.system }}
{{- if and .Values.worker.enabled .Values.worker.keda.enabled }}

  kubectl create secret generic {{ .Values.worker.secrets.redis.name }} \
    --from-literal={{ .Values.worker.secrets.redis.key }}='redis://:password@host:6379/0' \
    --from-literal=password='password' \
    -n {{ .Values.namespace.workers }}
{{- end }}
{{- if .Values.worker.keda.enabled }}

KEDA must already be installed in the cluster for the async worker to autoscale
(spec.triggers[0].type: redis in the ScaledObject).
{{- end }}

Check status:

  kubectl get pods -n {{ .Values.namespace.system }}
{{- if .Values.worker.enabled }}
  kubectl get pods -n {{ .Values.namespace.workers }}
{{- end }}
